## 📖 Overview
<a id="overview"></a>

**Sound Blocks** is an innovative music composition game designed for users of all skill levels, available on **Windows**. This application allows you to create music by placing and connecting colorful animated sound blocks on a grid, fostering an interactive and engaging environment for music creation. The **latest version** includes a playful visual interface that enhances your experience, making it a captivating tool for both aspiring musicians and casual gamers.

As a music creation tool, **Sound Blocks** encourages experimentation and creativity, making it suitable for non-musicians and those looking to explore sound design. The accessibility of its design ensures you can dive right in and start composing.
